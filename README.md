# PLP Python Week 5 Assignment

This project contains two small Python programs that practice importing built-in modules and creating a custom module.

## Files

- `password_generator.py` - Generates random passwords using the `random` and `string` modules.
- `helpers.py` - Contains the `tables_needed` and `welcome` functions.
- `main.py` - Imports `helpers` and uses both functions.

## Password Generator

Run:

```powershell
py password_generator.py
```

The program generates:

- One 8-character password using the default length
- One 12-character password

## Custom Module

Run `main.py`:

```powershell
py main.py
```

Expected output:

```text
Welcome to PLP, Amina!
8
4
```

Run `helpers.py` directly:

```powershell
py helpers.py
```

Expected output:

```text
3
```
